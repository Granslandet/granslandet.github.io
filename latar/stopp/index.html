Stopp. Vrid tillbaka tiden. Alla måsten du är tvungen att ha,. Att livet skulle bli en massa krav. Inte som när du var barn. När livet var enkelt.  Stopp —  vrid tillbaka tiden.  Varför hade vi så bråttom  att bli stora?  För det var ingen som sa  hur det var.  Ingen som sa  hur det var. Att smärtan kunde vara så stark. Att sorgen kunde kännas som om den slets ur bröstet. Att tårarna aldrig ville ta slut. Att inte våga säga hur det var.  Stopp —  vrid tillbaka tiden.  Varför hade vi så bråttom  att bli stora?  För det var ingen som sa  hur det var.  Ingen som sa  hur det var. För vad skulle hända om du bröt ihop? När du tappar kontrollen totalt? Och gråter som ett barn … För att någon frågar hur du mår.  Stopp —  vrid tillbaka tiden.  Varför hade vi så bråttom  att bli stora?  För det var ingen som sa  hur det var.  Ingen som sa  hur det /verkligen/ var. Att sorgen skulle vara så brutal.
